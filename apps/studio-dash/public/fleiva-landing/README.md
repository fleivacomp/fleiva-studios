# Assets da landing Flêiva

## `animal-caos.png`

Ilustração editorial com fundo transparente. Uso aprovado apenas na seção
sobre o caos operacional, sem transformá-la em mascote recorrente.

## `moire-fleiva.svg`

Padrão óptico responsivo nas cores da marca. Usar como fundo de uma única
seção, com baixa opacidade e sem texto longo diretamente sobre ele.

Exemplo:

```scss
.secao-moire {
  background:
    url('/fleiva-landing/moire-fleiva.svg')
    center / cover no-repeat,
    #f7f2e0;
}
```
